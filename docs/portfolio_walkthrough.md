# Recruiter / Interview Walkthrough

“I built a reproducible support-operations analytics pipeline that validates ticket data, calculates service KPIs, exposes P90 response and resolution behavior, connects SLA performance with CSAT, and segments escalations by priority and issue type.”

## What to show first

1. `src/support_analysis.py` — KPI and segmentation logic.
2. `sql/support_analysis.sql` — operational questions.
3. `docs/data_dictionary.md` — metric definitions.
4. `reports/executive_dashboard.md` — decision communication.
5. `tests/test_support_analysis.py` — analytical validation.

## What this proves

- Understands operational KPIs.
- Can move beyond averages into long-tail analysis.
- Can connect service metrics with customer outcomes.
- Can identify concentrated operational problems.
- Can package business analysis into a reproducible workflow.
