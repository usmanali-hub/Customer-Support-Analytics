# Decision Framework

## 1. Demand
Start with ticket volume by month, channel, priority, issue type, and team.

## 2. Service quality
Compare SLA attainment, first-response time, P90 response time, resolution time, and P90 resolution time.

## 3. Customer outcome
Use CSAT and low-CSAT rate alongside SLA status. This helps distinguish speed problems from broader experience problems.

## 4. Operational complexity
Inspect escalation and reopen rates by priority and issue type to identify concentrated sources of workload.

## 5. Action logic
- High volume + poor SLA → capacity or workflow review.
- Good average response + poor P90 → investigate long-tail cases.
- High escalation in one issue type → improve routing, documentation, or specialist coverage.
- Low CSAT despite SLA compliance → investigate quality, communication, or issue-resolution factors.

Segment-level conclusions should be checked for sufficient ticket volume before operational decisions are made.
